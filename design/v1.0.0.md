# v1.0.0: the first release

**Agreed:** 2026-11-15. Built on v0.0.3, with **features frozen**: what changes is what a review finds wrong, and the docs.

## The work

1. **A review of the code,** area by area (the machine core, the tape and sound, the system and the page's state, the UI and the lessons, the 3D and 2D views): its state machines and other complex logic drawn out and checked by reading, each bug found fixed with a test that fails without it, and the coverage of each state machine mapped to unit tests or browser checks.
2. **A review of the docs** against the code: README, CHANGELOG, docs/, design/, model/, lessons/.
3. **The README** for newcomers first: what the TRS-80 was, the first five minutes, what you can do; developers after.
4. **Media for posts:** `pnpm shots` and `pnpm video`, in English and Simplified Chinese.
5. **The owner's manual check,** then the release: the README's banner and screenshots, the version, the changelog, the tag.

## What 1.0.0 promises

- The link format is frozen (docs/ui-design.md, P8): a field is never renamed, dropped or read differently.
- No share link in 1.0.0 (design/roadmap.md).

## Found by the review and fixed

The reviews' findings, each fixed with a test that fails without it, are listed in the CHANGELOG's 1.0.0 entry. Among the smaller ones first thought of as for later, and fixed after all: two programs saved one after the other on a tape are now two recordings; a WAV recorded very quietly (down to about −50 dBFS) reads; the CPU tool's memory map is reached with Tab; SHIFT latched in 3D is latched in 2D.
