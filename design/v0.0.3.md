# v0.0.3: programs worth running, then the lessons

**Agreed:** 2026-11-15. The example programs first, then the lessons rewritten round them.

## Why

A visitor runs a program here for one of three reasons:

- **(A) To run the era's own software.** We do not host it: its rights are unclear. We say where it is, what of it runs here, and how to load it.
- **(B) To learn the machine and the ideas behind it.** The v0.0.1 samples each showed a mechanism (a frame drawn with SET, every byte POKEd, the screen filled by machine code) but gave a newcomer little reason to look. Each new one has a payoff on the screen and one idea, and belongs to a lesson.
- **(C) For fun,** with no wish to learn and no idea that old software can be found. Our own games, utilities and music, in the style of 1977–80: the genres of the time, with our own names, stories and pictures, never a copy of a particular program.

## Sound (S1)

The Model I has no speaker and no sound command. Its cassette output (port FFH, bits 0 and 1) is a level the program sets, and owners played it through an amplifier: the recorder's AUX lead moved to a small amplifier, which Radio Shack sold. Games of the time had sound this way, and music programs told the owner to connect one.

- **The amplifier is assumed connected and always on.** While the cassette motor is off, the level at port FFH is played as sound; while it runs, the tape's sound is played, as now. No new switch: Sound in the top bar mutes both.
- **From BASIC,** `OUT 255,1` and `OUT 255,2` make clicks and a low buzz. Tones and tunes need a few bytes of machine code, POKEd from DATA lines and called by USR, as the type-in music programs of the time did.
- About and the lessons say where the sound comes from.

## The catalogue (S2)

Programs in the top bar lists the programs in sections: **Learn**, **Games**, **Utilities**, **Music**, then **Find original programs…** and **Open a listing…**. Each program opens its dialog as now (description, listing, Type it in, Put its tape in).

- **Every program has a tape,** recorded by our own Model I as now (D7).
- **Type in faster.** A long program typed at the usual speed takes minutes. The dialog has a "Type in faster" switch, on by default for long programs: the machine runs many times faster while it types, as Fast tape does for a tape.
- **The programs' own text is the machine's:** upper case, in English, like `READY`. Their titles and descriptions are translated.

### Games (C)

1. **Moon lander:** thrust against gravity with little fuel.
2. **Worm:** steer a worm that grows as it eats.
3. **Bricks:** a bat, a ball and a wall.
4. **Meteors:** dodge the falling rocks, for a score.
5. **The lighthouse:** a small text adventure, about eight rooms, our own story.

### Utilities (C)

1. **Clock** in big block digits. You set the time when it starts: a bare Model I has no clock of its own, and programs of the time counted it with timed loops, as this one does.
2. **Calendar** for any month of any year.
3. **Biorhythm,** the late 1970s craze, charted from a birth date.
4. **Banner:** big letters scrolling across the screen.

### Music (C)

1. **Music box:** a few tunes in the public domain.
2. **Organ:** the keyboard's top row plays notes.

Games read the keys with PEEK and draw with PRINT @, as BASIC games of the time did, at the machine's real speed. Machine code is used only where BASIC is too slow to play.

## Original programs (S3)

**Find original programs…** opens a dialog of text, nothing hosted:

- **What runs here:** Model I Level II cassette software, as `.cas` files or `.wav` recordings, BASIC or machine code (SYSTEM), in 16 KB.
- **What does not:** disk software (`.dsk`, `.cmd`), programs for the Model III or 4 only, anything that needs 32 or 48 KB or the Expansion Interface.
- **How to load it:** Tapes ▸ Open a tape, then CLOAD, or SYSTEM and the program's name; Fast tape to wait less.
- **Where:** named archives, linked, with a note that rights vary and the visitor answers for what they download.

**Open a listing…** reads a plain-text BASIC listing (`.bas`, `.txt`) and types it in, as Type it in does: many programs of the time survive only as listings from magazines and books.

## The lessons (S4)

Rewritten round the Learn set: each step that runs a program runs one of these, and the Show me steps point at them. The teacher notes follow, in English.

## Order of work

1. Sound from port FFH, with a test that a known routine's tone comes out at its pitch.
2. A tool that runs a listing on the headless machine (type, run, press keys, read the screen), and a unit test that runs every program from its listing and from its tape.
3. The catalogue in sections, and Type in faster.
4. The Learn set; then the games, utilities and music.
5. Find original programs, and Open a listing.
6. The lessons and the teacher notes.
7. The ten languages for every new message; the browser checks, screenshots, the changelog, the README.

Each step is committed and pushed to `dev-v0.0.3`. Nothing is released before the owner approves.
