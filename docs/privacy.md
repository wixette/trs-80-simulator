# Privacy and what the page keeps

The simulator runs entirely in your browser. It has no server of its own beyond the files it is served from, no account, no analytics and no cookies.

**What it sends:** nothing. A tape (`.cas`, `.wav`), a BASIC file or a ROM you open is read in the page and never uploaded. A tape you save is made in the page and handed to your browser as a download. The archives named in Programs ▸ Find original programs open in a new tab only when you click them.

**What it keeps,** in your browser's local storage for this site, so that the page opens as you left it:

| Key | What |
|---|---|
| `trs80.lang` | the language you chose |
| `trs80.power` | whether the computer and the display were on |
| `trs80.view` | 2D or 3D |
| `trs80.dock` | the dock's tab, height and whether it was folded |
| `trs80.lessons` | the lesson open, and the steps ticked done |
| `trs80.sound` | sound on or off |
| `trs80.strip` | the helper strip folded or not |
| `trs80.rec`, `trs80.kbd` | the 2D view's recorder and keyboard drawers |

Nothing else: the machine's memory and tapes are not kept, and are gone when the page closes. Clearing this site's data in your browser forgets all of it. In a private window, or with site data blocked, nothing is kept and the page works the same.
